# fMRI_basics

This repository provides a beginner-friendly introduction to fMRI analysis, covering preprocessing, denoising, and downstream analysis.

## Preprocessing

- fMRIPrep tutorial (using the fMRIPrep container)
- XCP-D tutorial (using the XCP-D container)

## Analysis

1. Getting started with Python
   - `notebooks/00_getting_started.ipynb`
   - Walks you through the basics of Python and the packages you will need for basic analysis.

2. Understanding the fMRIPrep outputs
   - `notebooks/01_fmriprep_outputs.ipynb`
   - Explains which outputs are generated by fMRIPrep, how to use them, and key considerations.

3. Understanding the XCP-D outputs
   - `notebooks/02_xcpd_outputs.ipynb`
   - Explains which outputs are generated by XCP-D, how to use them, and key considerations.

4. Using XCP-D mean time series and connectivity analysis
   - `notebooks/03_mean_timeseries_and_confounds.ipynb`
   - Uses the XCP-D mean time series for a beginner-friendly functional connectivity workflow:
     - Load a real mean time series file from XCP-D
     - Compute a parcel-by-parcel correlation matrix
     - Flatten the matrix and remove the diagonal
     - Convert correlations to Fisher z values
     - Summarize connectivity at the network level
     - Run a simple seed-based connectivity analysis
